To replay the proofs, you should first install the SMT solvers CVC5
1.2.1 and Z3 4.13.4. Then you can run the following commands to
install Alt-Ergo, Rocq, Why3 and perform the verification.

```shell
# create a fresh opam switch with Alt-Ergo, Rocq, Why3, and MathComp
opam switch create test 5.4.1
. $(opam env)
opam remote add coq-released https://rocq-prover.org/opam/released
opam install rocq-core=9.1.0 why3=1.8.2 alt-ergo=2.6.1 coq-mathcomp-algebra-tactics

# detect provers and configure Rocq for Why3
why3 config detect

cat > why3-extra.conf <<EOF
[prover]
command = "$(which rocq) top -batch -l %f"
driver = "$(pwd)/why3/drivers/myssrdiv.drv"
editor = "coqide"
in_place = false
interactive = true
name = "Rocqssrdiv"
version = "9.1.0"
EOF

# compile and install the main Rocq development
cd rocq
rocq makefile -f _CoqProject -o Makefile
make
make install
cd ..

# replay the Why3 proofs
cd why3/pornin_gcd
for d in */; do why3 replay -L . --extra-config=../../why3-extra.conf $d; done
cd ../..
```

If you have not installed some of the SMT solvers, you can pass the
`--prover` option to the `why3 replay` command to only replay the
proofs for a given prover. For instance, if you just want to replay
the Rocq proofs, run the following command:

```shell
for d in */; do why3 replay -L . --extra-config=../../why3-extra.conf --prover=Rocqssrdiv $d; done
```

The main Rocq proof is in the file `rocq/pornin_gcd.v`. The WhyML
description of the algorithm as well as the proof sessions are in the
directory `why3/pornin_gcd/`. Our custom Why3 driver is
`why3/drivers/myssrdiv.drv`. 

Regarding the Rocq proofs contained in the various Why3 sessions, they
contain numerous `Axiom` and `Parameter` declarations, which were
automatically generated by Why3 to express the assumptions of the
current goal. When replaying the proof, Why3 will remove all these
declarations and regenerate them for scratch. In particular, they
cannot be used by the user to silently pass extra axioms.
